Color Palette

About Colors…
◉

The Classic Mac palette was 4-bit: 16 shades of gray. The color system is: #ffffff for content areas, #d4d4d4 for chrome and desktop, #000000 for all borders. There is no accent color — maximum contrast is the default state.

Buttons

Button Styles
↓

Mac buttons use four inset box-shadows: inset -1px -1px #000, inset 1px 1px #fff, inset -2px -2px #888, inset 2px 2px #e0e0e0. The Default button (dialog accept action) adds a bold double border: inset 0 0 0 2px #000. Press state flips all shadows.

Form Inputs

System Preferences
⊙

Text inputs: white background, border: 1px solid #000, inset shadow inset 1px 1px #888. Checkboxes are square (14px) with a ✓ mark when checked. Radios are circles with a black dot. Popup menus use the bevel button appearance with a ▾ arrow.

Cards

Each card is a Mac window — complete with titlebar, close box, drag stripes, and content area. The hatched backgrounds reference Classic Mac application window fill patterns. Drop shadow: 2px 2px 0 #888, 3px 3px 0 #555.

Four Inset Shadows

The entire depth system lives in four inset box-shadow values. White top-left, black bottom-right, mid-gray outer, near-white inner. One recipe, infinite surfaces.
