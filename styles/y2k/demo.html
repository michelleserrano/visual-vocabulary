Color Palette

01
💿

The Y2K palette is holographic — #ff77e9 pink, #7b7bff periwinkle, #74d4ff baby blue, and #a8f0c8 pastel green shift like a CD in sunlight. No matte surfaces allowed. All fills should be gradient or frosted-glass. The iridescent swatch (bottom right) is the system soul — it animates endlessly.

Typography Scale

Fredoka is bubbly and approachable — Y2K's optimism in a typeface. Every letterform is slightly rounded, matching the UI's bubble shapes. Use weight 300–700; the geometric softness is the point. Never swap for a condensed or high-contrast serif — that would break the spell.

Buttons

03
🫧

Every button is a bubble: gradient fill, shine overlay, soft shadow. Primary = pink-to-periwinkle gradient. Secondary = chrome frosted glass. Ghost = transparent with gradient border. The ::before shine overlay must always be present — it's what separates Y2K from flat design.

04

Form Inputs

04
🔮

Input fields are frosted glass bubbles — rgba(255,255,255,0.78) background with a soft inset shadow. Focus adds a pink glow ring: box-shadow: 0 0 0 3px rgba(255,119,233,0.2) — the bubble activates. Checkboxes are circular. Toggles have gradient active tracks. Nothing is square.

05

Cards

05
💿

Cards are chrome surfaces — gradient underlay, shine overlay, very rounded (border-radius: 40px). Like holding a CD case. On hover they lift 6px with expanded shadow. Card thumbnails use pastel gradient fills — no photos, no flat fills.
