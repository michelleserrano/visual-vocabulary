03

Buttons

↓
The single most important element. Every button: background: #c0c0c0; box-shadow: var(--bevel-out). On press: box-shadow: var(--bevel-in). No color change. No animation. Just the shadow flip. The dotted inner outline marks the default button.

THE BEVEL SYSTEM — THE ONE TRICK:
/* Raised (button, panel, dialog frame) */
--bevel-out:
  inset -1px -1px 0 #000000,  /* black · outer BR */
  inset  1px  1px 0 #ffffff,  /* white · outer TL */
  inset -2px -2px 0 #808080, /* gray · inner BR */
  inset  2px  2px 0 #c0c0c0; /* chrome · inner TL */

/* Sunken (input field, inset panel) */
--bevel-in:
  inset  1px  1px 0 #000000,  /* black · inner TL */
  inset -1px -1px 0 #ffffff,  /* white · inner BR */
  inset  2px  2px 0 #808080, /* gray · inner TL */
  inset -2px -2px 0 #c0c0c0; /* chrome · inner BR */

Form Inputs

⊙
Inputs = white rectangles with box-shadow: var(--bevel-in). They are holes cut into the chrome. Checkboxes: 13×13 bevel-in squares with a ✓ mark. Radios: round bevel-in circles with a filled dot. Selects: white input + bevel-out arrow button attached right. Toggles: scrollbar-style slider with bevel-out thumb.

Navigation · Windows Explorer

◻
Explorer is Win95's navigation paradigm: icon toolbar buttons (bevel-out at rest, bevel-in on press), an address bar (bevel-in text input + Go button), split-pane tree/file view. Selected item = navy background + white text. Click files to select them.
