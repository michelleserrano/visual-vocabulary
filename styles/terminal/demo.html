// Design System

One Color Rule

A monochromatic system achieves hierarchy through opacity, not hue. The amber phosphor is the only light source — vary its intensity, not its wavelength.

// Engineering

Zero Radius Spec

CRT terminals had sharp corners. Every panel, button, and input in Terminal Mono follows suit. Border-radius: 0. The rectangle is structurally honest — no softening of edges.

// Accessibility

Amber Contrast

Amber #FFB000 on near-black #0A0800 achieves 12.5:1 contrast ratio. The primary text level (0.92α) still passes WCAG AA at 11.5:1. The low tones are for decoration only — never interactive affordance.
