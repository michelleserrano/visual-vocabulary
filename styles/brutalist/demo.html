Brutalist Web

A design language that rejects decoration. Raw HTML aesthetics — every border is structural information, every element is a hard rectangle. The browser's default is the starting point, not something to overcome.

system fonts only no shadows extreme contrast deliberate ugliness

Buttons

03

Brutalist buttons are just rectangles. No shadow, no gradient, no radius. The border IS the button. Hover = invert (black fill, white text). Press = offset 2px. Primary hover = red fill.

04

Form Inputs

04
⊙

Raw HTML inputs styled minimally. The browser's affordance is sufficient. Labels: all-caps Courier New. Inputs: 3px solid black border at rest, red border on focus, no outline. Checkboxes: 24px squares. Toggles: rectangles that slide.

05

Cards

05
▣

Cards are bordered boxes. Content hierarchy is bold type and horizontal rules — not visual layers. Hover adds a hard offset shadow: 4px 4px 0 #000. No rounded corners. No gradients in thumbnails. Category color fills are structural.
